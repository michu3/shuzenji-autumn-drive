# 修善寺・秋の紅葉絶景ドライブツアープラン 2026 (スマホ旅のしおり)

2026年11月下旬の紅葉ハイシーズンに、**「往路の伊豆スカイライン稜線紅葉」「修善寺自然公園もみじ林」「達磨山展望台からの富士山大パノラマ」「修善寺温泉街散策」「名物手打ち蕎麦ランチ」**を満喫し、午後の東名上り大渋滞を避けて帰宅するスマート日帰りドライブツアーです。

運転席のスマホホルダーから片手親指でワンタップナビ起動できる**専用モバイルWebアプリ（`index.html`）**および**カレンダー一括登録ファイル（`shuzenji_tour_202611.ics`）**を同梱しています。

## 2. 往路に組み込んだ紅葉ドライブコースの魅力

### 【伊豆スカイライン（熱海峠IC 〜 亀石峠IC）＆ 滝知山展望台】
* **なぜこのルートなのか:**
  * 首都圏から小田原厚木道路・箱根新道を経て熱海峠からアプローチ。
  * 標高400〜800mの稜線を約20km走る有料道路（普通車430円）。左右に相模湾・初島と駿河湾、正面に富士山を望む日本屈指のスカイラインです。
  * 11月下旬、沿線のカエデやクヌギの紅葉、ススキの銀色の絨毯が朝の光に映えます。
  * 途中の「滝知山展望台（無料P）」は、車を停めて数歩で360度の大パノラマが広がる絶景休憩スポットです。
  * 亀石峠ICから県道19号線を下れば、信号も少なく約15〜20分で修善寺の玄関口へ一気に降りられます。

## 5. モバイルWebナビ（`index.html`）の使い方

本フォルダの `index.html` をブラウザ（Safari / Chrome）で開くと、以下の機能が利用できます：

1. **ワンタップナビ起動:** 各カードのナビボタンまたは画面下部の固定ボトムバーから、Google Mapsアプリが即座に起動します。
2. **リアクティブ追従:** 各スポットの「通過済」チェックを入れると、画面下部のボトムナビが自動的に次の目的地へ切り替わります。
3. **ランチセレクター:** ランチカードのタブ（なゝ番 / やまびこ / 朴念仁）をタップすると、店舗情報とナビURLが瞬時に切り替わります。
4. **ホーム画面に追加 (PWA):** スマホブラウザの共有メニューから「ホーム画面に追加」を行うと、全画面ネイティブアプリ感覚で利用できます。
5. **カレンダー同期:** ヘッダーのボタンから Googleカレンダーへのワンタップ登録、または同梱の `shuzenji_tour_202611.ics` をダウンロードしてiOS/Androidカレンダーに一括インポートできます。
